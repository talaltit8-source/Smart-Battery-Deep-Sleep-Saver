# 🔋 Smart Battery & Deep Sleep Saver

A system-level battery optimizer for Magisk and KernelSU designed to prolong device endurance by enforcing a deeper sleep state and reducing aggressive standby power drainage.

Developed by **@dr.tit** 🚀

---

## 🚀 Features
- **Advanced Deep Sleep:** Forces the kernel to enter extreme power-collapse states efficiently as soon as the screen turns off.
- **Radio Standby Optimization:** Adjusts background Wi-Fi and mobile radio scanning intervals to prevent idle battery drain.
- **Zero Perf Loss:** Optimizes only idle and standby states, ensuring maximum performance remains untouched when you are active.

---

## 🛠️ Installation
1. Download the `Smart-Battery-Saver by Dr.tit.zip` from this repository.
2. Flash it via **Magisk** or **KernelSU**.
3. Reboot your device.
